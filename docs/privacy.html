PRIVACY

What Open Game
does with your data.

Last updated: October 21, 2026

This page describes the Open Game website, the browser Blueprint Studio, and the local CLI/MCP tools in this repository. Open Game does not operate a hosted account system or game-generation backend in this release.

Website visits

The website source does not include an analytics SDK, advertising pixel, or cookie-based tracking. It loads the Manrope and DM Mono fonts from Google Fonts, so a browser that permits the request contacts Google to fetch those font files. The website is hosted through the configured site provider (currently Vercel); GitHub also hosts this project's source and issue tracker. Those providers may process request and security logs under their own privacy terms.

Blueprint Studio

The Studio saves the in-progress game brief in your browser's local storage on that device. The saved draft stays in that browser unless you export it, share it, or otherwise send it yourself. Use the Studio's clear/reset control or clear this site's browser storage to remove the saved draft. Private or sensitive information should not be entered into a brief that you plan to share.

CLI and MCP server

The CLI and MCP server run on your computer. The MCP server reads and writes files within its configured workspace. Open Game itself does not send those project files to an Open Game service. Your connected coding agent or model provider may receive prompts, files, or tool results according to the provider and agent configuration you choose; review that provider's privacy terms and permissions.

Downloads, issues, and third-party services

Installing from GitHub, visiting GitHub Releases, or posting an issue involves GitHub and is governed by GitHub's policies. Issues and pull requests in this public repository may be visible to anyone. Do not include secrets, personal data, or private game materials in public issue reports.

Changes and questions

We may update this page when the product or hosting changes. The date above identifies the latest revision. To ask a privacy question or report a concern, open an issue in the Open Game repository; avoid posting personal or confidential details in a public issue.

NOT LEGAL ADVICE

This notice describes the current repository implementation and hosting arrangement; it is not a guarantee about third-party provider practices. Check the linked providers' current policies.
