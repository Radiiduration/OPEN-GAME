# Open Game agent instructions

When the user asks you to create or expand a game in this repository, follow the **Open Game Creator** skill at `skills/open-game-creator/SKILL.md`.

The skill is an execution contract for the connected coding LLM: inspect the real project and toolchain, implement in engine source files, build and run the game, observe and fix failures, then continue through the full brief. Do not stop after generating a blueprint, roadmap, or first playable slice when more implementation is possible. Keep a verified continuation record if the task must span runs.

Treat a user's large game idea as the intended destination. Build it through coherent, playable milestones while preserving its systems, world, and identity in editable project files. Do not reduce the request to a tiny unrelated demo or stop at a pitch when implementation is possible.

All game content must be original or properly licensed. Broad genre inspiration is fine; do not reproduce another game's distinctive characters, story, setting, maps, branding, art, audio, UI, or code. No process can promise that a project is lawsuit-proof.

When the repository is used as context for a different user's game project, work in that project and keep Open Game's own source files unchanged unless the user asks to modify Open Game itself.
