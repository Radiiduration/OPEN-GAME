## Caption

What if your original game idea had a clearer path from vision to playable project?

Open Game helps creators shape an original game brief, connect its systems, and hand that context to a coding LLM. The connected agent writes the game in an engine project and can build, play-check, and iterate with the tools available in its environment.

The repository includes project planning and progress tools plus an original browser-racing example. The LLM does the game implementation; Open Game is not a one-prompt AAA compiler.

Explore the project: https://opengame-ecru.vercel.app/
Visit the GitHub repo: https://github.com/Radiiduration/OPEN-GAME
