Your agent’s workflow.

Install the CLI from GitHub, check your local tools, and open the Blueprint Studio. The MCP server connects the same project tools to your coding agent.

BEFORE YOU START

Git · Node.js 20 or newer · a coding agent. Game engines are optional until you build a project that needs one.

CONNECT YOUR AGENT

Bring the workflow
to your coding agent.

Run the local MCP server over stdio and add it to the MCP configuration supported by your agent. Set a workspace folder where projects may be created, then restart the agent.

Read setup steps for the MCP server ↗
MCP CONFIG / EXAMPLE
{
  "mcpServers": {
    "open-game": {
      "command": "open-game",
      "args": ["mcp"],
      "env": {
        "OPEN_GAME_WORKSPACE": "/absolute/path/to/game-projects"
      }
    }
  }
}

Use an absolute path for your own workspace. The server creates projects only inside that configured folder.

GUIDES + FAQ

Clear about what
it does today.

Start with the docs, check the limits, and use the tools that fit your environment.

Does Open Game generate any finished game from one prompt?

No. A creator's brief starts an end-to-end coding-agent task. The connected LLM implements the game, and scope, quality, assets, and builds depend on that agent and its environment.

Is the LLM included in this package?

No. Open Game supplies the agent workflow and project tools. Use your own coding agent and configure its model/provider separately.

Which engines can I use?

The project schema is engine-neutral and current adapters include initial Godot, Unity, and Unreal operations. Build support is partial and depends on the engine, export tools, presets, and project configuration.

Does Open Game provide online multiplayer hosting?

No. The toolkit can represent multiplayer requirements and includes a bounded example server. It does not provision production matchmaking, identity, cloud saves, or hosting.

Can it make a copyright-safe clone?

Open Game supports original projects inspired by broad genres. No scan or workflow can promise legal safety; use original or properly licensed material.

How do I contribute or get support?

Read the contribution notes in the repository README, open an issue, and include your environment and exact command output where relevant.
